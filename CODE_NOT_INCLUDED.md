# Code not included

This public repository currently contains the project documentation, not its source code. The code will open during the judging period under the review-only license: judges and the community may read and clone it to evaluate it, but may not modify it.

## Español

Este repositorio público contiene por ahora la documentación del proyecto, no su código fuente. El código se abrirá durante el periodo de los jueces bajo la licencia de solo revisión: el jurado y la comunidad podrán leerlo y clonarlo para evaluarlo, pero no modificarlo.
